# Nits de Llegenda

Web del festival **Nits de Llegenda**, és una pàgina web dedicada a un festival de cinema a l'aire lliure celebrat a la ciutat de Lleida.

La web ofereix informació sobre l'esdeveniment, les dates i l'itinerari de les projeccions, els patrocinadors, una galeria d'imatges, una secció de preguntes freqüents, informació de contacte i un formulari de registre per als assistents.

## Tecnologies

- **HTML5** per a l’estructura i les pàgines del lloc.
- **CSS3** per als estils i el disseny adaptable.
- **JavaScript** per a la interactivitat, la galeria i la validació dels formularis.
- **Firebase Hosting** per publicar el lloc web.

És un lloc web estàtic i no necessita instal·lar dependències ni compilar-se.

## Obrir-la localment

1. Opció 1: Obrir directament al navegador
Descarrega o clona el repositori i obre el fitxer:

index.html
amb qualsevol navegador web modern.

2. Opció 2: Utilitzar un servidor local
Des de la carpeta del projecte, executa:

http-server .
A continuació, obre al navegador:

http://localhost:8000

3. Visita [http://localhost:8000](http://localhost:8000).
